# ChatGPT Goal Runner Pilot

Repositorio público de pruebas para validar desarrollo autónomo desde ChatGPT Chat y Tasks, con GitHub Actions como ejecutor cloud.

Este repositorio es exclusivamente experimental. No contiene credenciales, datos privados, infraestructura de producción ni acceso a Atlas.

El prototipo se desarrolla en ramas aisladas y se revisa mediante pull requests. No se permite fusión automática ni despliegue en producción.
